# 日々 Hibi Task

> **Work in progress** · em construção

**EN** — A minimal task timer that lives entirely in your browser: describe an intention, choose a duration, start. No backend, no database, no accounts — history is kept in `localStorage`. The design follows *ma* (deliberate emptiness): ink on paper, two named themes — **gofun** (shell white) and **sumi** (ink) — and one rule that holds it together: the vermillion accent only appears while time is running.

**PT** — Um timer de tarefas minimalista que vive inteiro no navegador: descreva uma intenção, escolha a duração, comece. Sem backend, sem banco, sem conta — o histórico fica no `localStorage`. O design segue o *ma* (o vazio deliberado): tinta sobre papel, dois temas nomeados — **gofun** (branco de concha) e **sumi** (tinta) — e uma regra que segura tudo: o acento vermelhão só aparece enquanto o tempo corre.

## Stack

Next.js (App Router) · TypeScript · CSS Modules — no UI libraries.

## Running locally

```bash
npm install
npm run dev
```
